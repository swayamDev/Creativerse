# 🎨 Creativerse – Where Creativity Meets Code

A playground of interactive UI/UX experiments, animation concepts, and inspiring design patterns for web developers.

---

## 🚀 Live Demo

🔗 [Live Site](https://creativerse-ten.vercel.app/)

![Creativerse Screenshot](/public/screenshot.png)

---

## 📖 About the Project

Creativerse is a curated collection of delightful frontend micro-interactions, motion effects, and design-driven components built using React and Framer Motion. It is designed to inspire and serve as a sandbox for learning creative web development patterns.

---

## 🎯 Features

- 🌀 Smooth scroll-based animations
- 🖱️ Hover-to-reveal effects
- 📜 Infinite marquee text
- 📌 Sticky side-scroll layouts
- 💎 Responsive and accessible

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, Framer Motion
- **Icons:** React Icons
- **Deployment:** Vercel

---

## 📦 Installation

```bash
git clone https://github.com/swayamDev/Creativerse.git
cd Creativerse
npm install
```

---

## ▶️ Usage

```bash
npm run dev
```
